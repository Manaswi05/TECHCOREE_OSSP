# ForgeOS

ForgeOS is the OSSP course project consisting of two components:

* **Shellforge** – User-space Unix-style shell developed in C.
* **NanoKernel** – Kernel-space components developed for the project.

## Structure

```text
ForgeOS/
├── Shellforge/
└── NanoKernel/
```

**Team:** TECHCORE
**Course:** Operating Systems and System Programming (OSSP)
